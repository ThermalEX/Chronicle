# Chronicle 更新日志

已发布版本的正文按发布时间倒序汇总于此；GitHub Release 页面负责显示版本大标题。未发布的本地测试版单独标注。

## v1.3.3-beta

### 新增

- 新增 Galgame 存档扫描：选择合集文件夹，递归识别多层目录中的游戏，检查游戏内及常见 Windows 用户目录中的已有存档。
- 首批支持 Kirikiri、Ren’Py、RPG Maker MV/MZ/XP/VX/VX Ace、Wolf RPG，以及可执行文件搭配常见存档目录的识别。显示游戏名称、引擎、路径及匹配依据，勾选后批量加入资料库；未生成存档的游戏只显示提示。
- 扫描结果本地保存，可手动刷新或取消；添加前重新检查路径，跳过已有来源，逐项显示添加或初始备份失败原因。

### 改进

- 顶栏游戏存档识别入口改为游戏手柄图标；识别窗口增加 Steam 和 Galgame 分页，分别使用 Steam 和书本图标。
- 补充中英文界面与新手教程入口说明。

### 测试重点

- 多层合集中的多部游戏是否分别识别，存档路径是否准确，是否漏掉已有存档或混入游戏资源。
- 外部用户目录名称匹配、扫描取消、重新打开后的缓存，以及批量添加和重复来源处理。

### 已知限制

- 仅支持 Windows；自定义引擎、加密配置与特殊存档位置可能需要手动添加，不保证覆盖全部 Galgame。
- 跳过链接目录、目录联接和云端占位文件；本次不接入在线路径数据库。

### Windows 下载

- 安装版：`Chronicle_1.3.3-beta_x64-setup.exe`；便携版：`Chronicle-1.3.3-beta-windows-x64-portable.zip`。
- 下载后可使用 `SHA256SUMS.txt` 校验文件；Windows 构建未签名。
- 此版本标记为测试版，仅测试版更新渠道接收，不替换最新正式版。

## v1.3.2

### 新增

- 新增简体中文与英语界面，可在设置或首次使用时切换，立即生效并保存选择。
- 首次使用先选择语言，搭配 Hello、你好、Hola 等问候动画；语言卡片只显示语言名称。
- 顶部工具栏新增 Steam 图标，打开游戏存档识别弹窗：识别 Windows Steam 安装目录和多个游戏库，支持搜索、逐来源勾选和批量添加。扫描结果保存在本机，再次打开无需重新扫描，可手动刷新。
- 日间／夜间模式切换移至页面右下角的圆形按钮。
- 从本机 Steam 配置识别昵称，按账号分组显示存档来源；添加后以“游戏名 · 昵称”命名，未确定账号的来源单列为本机存档，昵称随扫描结果缓存。
- 路径库使用 Ludusavi Manifest，支持本机缓存与手动更新，并补充检查 Steam userdata 云存档目录；添加时跳过已有来源，可选择立即备份。

### 修复

- 修复首次欢迎页选择语言后文案没有立即切换的问题，语言选择会保存并在下次启动时恢复。
- 修复旧 Steam 扫描缓存中的账号来源被全部归为本机存档的问题；读取时补齐账号信息，没有昵称时按用户 ID 区分。
- 修正教程的 Steam 步骤编号，点击图标可打开识别窗口，关闭窗口后进入教程完成页。

完整更新记录见 [更新日志](https://github.com/ThermalEX/Chronicle/blob/main/docs/changelog.md)。

- 便携版：解压后运行 `Chronicle.exe`，资料库保存在程序旁的 `Chronicle-data`。
- 本版本未签名，请使用 `SHA256SUMS.txt` 校验下载完整性。

## v1.3.0

### 新增

- 新增逐存档备份排除规则，支持通配文件名和目录；自动监听忽略排除项，恢复时保留排除内容。
- 新增快照星标锁定，自动清理保留锁定节点，手动删除前必须解锁；云端同步支持同一快照的锁定状态和备注变更，无需重新上传压缩包。
- 新增 Windows 注册表子键备份，可与文件来源组合使用；支持合并、覆盖恢复和覆盖二次确认，恢复前生成安全快照。首版支持 HKCU/HKLM 的 64 位视图，不包含注册表自动监听。

### 同步与性能

- 同步所有存档时按云端源并行执行，同一源内保持顺序，减少多个云端相互等待。
- 优化 GitHub 同步和删除的请求链路，减少重复读取、无变化提交和重复配置上传。

### 修复

- 修正数量清理的节点顺序，保留最新普通快照；锁定节点和安全快照不占普通保留数量。
- 恢复时预检文件与目录冲突，避免旧快照覆盖受排除规则保护的目录或后代；拒绝快照中的越界解压路径。
- 自动备份在合并窗口结束后只保存一份最新快照，避免一次保存产生两份节点；恢复文件期间不触发自动备份。
- 修复删除 GitHub 存档时缺少 tree.mode 导致的 HTTP 422 错误。
- 调整五个快照操作按钮的列宽，修复时间线底部多余横向滚动条和右侧空隙；提高同步按钮进度条的辨识度。

### 已知限制

- 注册表备份仅支持 Windows 下 HKCU/HKLM 的 64 位视图，暂不监听注册表变化；输入路径不包含“计算机”前缀，权限不足时不会自动提权。

### Windows 分发

- 安装版：`Chronicle_1.3.0_x64-setup.exe`，支持选择安装目录。
- 便携版：`Chronicle-1.3.0-windows-x64-portable.zip`，解压运行，资料库存放在程序旁的 `Chronicle-data`。
- Windows 构建未签名；下载后请用随附的 `SHA256SUMS.txt` 校验文件完整性。

## v1.2.0

### 自动备份与后台运行

- 新增逐存档自动备份：监听本地文件或文件夹变化时立即保存变化瞬间，并在 5 秒合并窗口结束后补充一份最新快照。
- 新增逐存档自动上传：为存档启用后，新建快照会上传至全部未暂停的云端同步源；与自动备份同时开启即可完成监听、快照、上传。
- 自动上传失败时保留本地快照，记录诊断并提示用户手动同步。
- 关闭主窗口可最小化到托盘；托盘菜单提供“显示 Chronicle”和“退出 Chronicle”，后台监听在托盘期间持续运行，并显示系统通知。

### 更新与界面

- 关于页新增正式版/测试版更新频道、启动时检查更新开关和手动检查入口。
- 发现新版本时显示更新说明，可复制链接、在浏览器打开，或下载校验后启动 Windows 安装包。
- 新建和编辑存档可分别设置“自动备份”与“自动上传”，存档名称旁以状态标签显示配置；点击名称或标签可直接进入编辑。
- 存储与备份设置支持调整文件合并时间，并可一键开启或关闭所有存档的自动备份、自动上传。
- 分类树补齐 VS Code 风格展开与收起箭头；三点菜单支持点击外部关闭。

### 修复

- 恢复时间节点时不再触发自动备份监听，避免恢复动作额外生成“自动备份”快照。
- 修复 WebDAV 对包含中文等特殊字符的存档执行 `MOVE` 时可能返回 HTTP 400 的问题。
- “使用设置”现在只应用云端应用设置，不会读取或应用云端分类层级。
- “覆盖上传”会同步同一存档在 `category-tree.json` 中的专属分类分支；下载分类层级仅应用当前存档对应的分类。

### Windows 分发

- 提供可选择安装目录的 NSIS 安装版和便携 ZIP。

## v1.0.0

### 主要亮点

- 本地 7z 时间线快照，支持恢复、备注、保留策略、回收站和诊断功能。

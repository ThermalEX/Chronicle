# Chronicle 更新日志

已发布版本的正文按发布时间倒序汇总于此；GitHub Release 页面负责显示版本大标题。

## v1.2.0-beta（预发布）

### 自动备份与后台运行

- 新增逐存档自动备份：可监听本地文件或文件夹变化，静默时间结束后自动创建“自动备份”快照。
- 新增逐存档自动上传：为存档启用后，新建快照会上传至全部未暂停的云端同步源；与自动备份同时开启即可完成监听、快照、上传。
- 自动上传失败时保留本地快照，记录诊断并提示用户手动同步。
- 关闭主窗口可最小化到托盘；托盘菜单提供“显示 Chronicle”和“退出 Chronicle”，后台监听在托盘期间持续运行。

### 存档与界面

- 新建和编辑存档可分别设置“自动备份”与“自动上传”，存档名称旁以状态标签显示配置；点击名称或标签可直接进入编辑。
- 存储与备份设置支持调整文件静默时间，并可一键开启或关闭所有存档的自动备份、自动上传。
- 分类树补齐 VS Code 风格展开与收起箭头；三点菜单支持点击外部关闭。
- 更新产品简介为“本地云端通用文件快照管理器”。

### 修正

- “使用设置”现在只应用云端应用设置，不会读取或应用云端分类层级。
- “覆盖上传”会同步同一存档在 `category-tree.json` 中的专属分类分支。
- 下载时勾选分类层级只应用该存档对应的分类；若 `category-tree.json` 缺少该条目，会从远端 `catalog.json` 提取同一存档的分类祖先，不会使用其他存档的分类。

### Windows 分发

- 提供可选择安装目录的 NSIS 安装版。
- 提供便携 ZIP：首次运行会在 `Chronicle.exe` 同级创建 `Chronicle-data/`，不会回退到 App Local Data。
- 本次为预发行测试版。请在重要资料库上保留独立备份，并先在测试资料库验证自动监听、托盘后台运行与云端同步权限。

## v1.1.0

### 更新日志

- 支持多个同步源：可分别启用、暂停和检测；一次同步会发送到全部已启用来源。
- 支持 Apache OpenDAL 服务模板：S3 / 兼容 S3、Backblaze B2、Azure Blob、Google Cloud Storage、阿里云 OSS、腾讯云 COS、华为云 OBS、火山引擎 TOS、OpenStack Swift、GitHub 和 WebDAV。
- 云端仓库支持预览、刷新、覆盖上传/下载、单条目同步和删除；切换来源后会自动刷新。
- 配置或同步开关变更后，关闭设置会提示保存；来源需通过测试后才能保存新的 OpenDAL 凭据。
- 时间节点支持备注、详情面板、单节点恢复/同步/删除，并改善窄窗口下的操作按钮布局。
- 通知统一使用成功/错误颜色，并始终显示在设置和确认窗口上方。

### Windows 分发

- 安装版可选择安装位置，资料库保存在 App Local Data。
- 便携版首次运行会在 `Chronicle.exe` 同级创建 `Chronicle-data/`。
- Windows 构建未签名；下载后请用随附的 `SHA256SUMS.txt` 校验文件完整性。

## v1.1.0-beta（预发布）

### 云端同步

- 新增 Apache OpenDAL 通用同步源，支持 S3 / 兼容 S3、Backblaze B2、Azure Blob、Google Cloud Storage、阿里云 OSS、腾讯云 COS、华为云 OBS、火山引擎 TOS、OpenStack Swift、GitHub 和 WebDAV。
- 保留 GitHub 与 WebDAV 兼容源；GitHub 兼容源继续支持指定分支与创建仓库，坚果云继续使用兼容 WebDAV 的覆盖上传回退行为。
- 同步源必须完成写入、读取、列举、删除及临时对象清理测试才可启用；测试结果显示为绿色/红色 Toast，已通过的来源会显示绿色状态点。
- OpenDAL 机密字段仅存 Windows 凭据管理器；表单会明确提示已保存的凭据。更改配置或密钥后需要重新测试。
- 新增“启动时检测云端”设置，首页状态区会区分未检测、检测中、可用和具体同步源不可用。

### 存档与界面

- 时间节点支持备注、恢复、单节点同步和删除；备注会写入资料库 JSON，随同步在其他设备显示。
- 左侧选择文件夹后，主区显示规范化的相对路径与对应目录内容。
- 新增日间/夜间模式、六种低饱和主题色与灰色模态遮罩；夜间图标对比度、按钮尺寸和悬浮提示均已调整。
- 关于页展示应用图标、版本与作者；顶栏状态和云端入口的可读性得到改善。

### Windows 分发

- 提供可选择安装目录的 NSIS 安装版。
- 提供便携 ZIP：首次运行会在 `Chronicle.exe` 同级创建 `Chronicle-data/`，不会回退到 App Local Data。
- 本次为预发行测试版。请在重要资料库上保留独立备份，并先在测试资料库验证云端服务权限。

完整填写说明见仓库中的 [云端同步配置指南](https://github.com/ThermalEX/Chronicle/blob/beta/docs/cloud-setup.md)。

## v1.0.0

### 主要亮点

- 本地 7z 时间线快照，支持恢复、备注、保留策略、回收站和诊断功能。
- 支持 WebDAV 和 GitHub 仓库同步，包括冲突处理和多数据源同步。
- 支持文件夹导航、标签、快照搜索、六种配色主题，以及浅色/深色外观模式。

### Windows 分发

- `Chronicle_1.0.0_x64-setup.exe`：NSIS 安装程序，支持按当前用户或整台计算机安装，并可选择安装目录。其数据资料库存储在 `%LOCALAPPDATA%\\com.thermalex.chronicle\\Chronicle`。
- `Chronicle-1.0.0-windows-x64-portable.zip`：解压后即可运行。程序会在 `Chronicle.exe` 所在目录旁创建 `Chronicle-data` 文件夹，并且绝不会转而使用 App Local Data（本地应用数据目录）。

> **安全提示：** 此 Windows 版本目前尚未进行数字签名。

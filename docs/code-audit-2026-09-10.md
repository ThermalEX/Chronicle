## 保留与后续审查点

- 保留旧凭据指纹兼容、根目录约束、删除保护与凭据先于设置保存的顺序。这些不是可删的重复防御。
- GitHub 批量提交与 WebDAV/OpenDAL 的写入方式不同，只复用纯数据转换，不强行统一整个上传/下载流程。
- 浏览器 IndexedDB 与桌面文件仓库是两个实际运行后端，不能因为接口相似就删除一套。
- `App.vue` 与 `cloud.rs` 仍较大，但拆成更多文件不会自动减少复杂度；本轮不做大范围搬家。
- 静态审查风险：`CloudCenterDialog.loadPreview` 在等待远端期间允许切换来源，旧请求可能覆盖新来源结果；后续应通过请求归属校验及异步竞态测试处理。
- 严格 Clippy 仍报告 `chronicle-sync/src/remote.rs` 的 21 项既有 lint，主要为公开接口错误文档、文档标记和按值传参。未通过关闭 lint 掩盖问题。

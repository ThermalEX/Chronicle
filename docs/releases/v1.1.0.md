# Chronicle v1.1.0

## 更新日志

- 支持多个同步源：可分别启用、暂停和检测；一次同步会发送到全部已启用来源。
- 支持 Apache OpenDAL 服务模板：S3 / 兼容 S3、Backblaze B2、Azure Blob、Google Cloud Storage、阿里云 OSS、腾讯云 COS、华为云 OBS、火山引擎 TOS、OpenStack Swift、GitHub 和 WebDAV。
- 云端仓库支持预览、刷新、覆盖上传/下载、单条目同步和删除；切换来源后会自动刷新。
- 配置或同步开关变更后，关闭设置会提示保存；来源需通过测试后才能保存新的 OpenDAL 凭据。
- 时间节点支持备注、详情面板、单节点恢复/同步/删除，并改善窄窗口下的操作按钮布局。
- 通知统一使用成功/错误颜色，并始终显示在设置和确认窗口上方。

## Windows 分发

- 安装版可选择安装位置，资料库保存在 App Local Data。
- 便携版首次运行会在 `Chronicle.exe` 同级创建 `Chronicle-data/`。
- Windows 构建未签名；下载后请用随附的 `SHA256SUMS.txt` 校验文件完整性。

# Chronicle 1.1.0：OpenDAL 通用云端同步适配计划

## 已确认目标

仅完成源码、测试与文档，不构建安装包、不发布 Release。保留现有 GitHub（任意分支、建仓、批量提交）与 WebDAV（包括坚果云回退）行为和凭据。新增 OpenDAL 通用源；单活动同步源；不增加个人云盘 OAuth。

## 实施任务

### Task 1: 通用同步源端到端适配

- 在 chronicle-sync 引入固定稳定版 OpenDAL，启用 github、webdav、s3、b2、azblob、gcs、oss、cos、obs、tos、swift。以实际发布版本 API 为准，不盲用网站开发版。
- 增加 RemoteStore 接口及适配器，统一同步协议读取、写入、上传下载、列举、删除、能力检测；重命名按能力支持，不强制对象存储提供原子 rename。保留旧 GitHub 批量提交语义，不降级为逐文件提交。
- 配置格式 v3：legacy_github、legacy_webdav、opendal；旧 v2 provider github/webdav 无损映射，保留 id、credentialRef、branch、所有路径。OpenDAL 配置含 scheme、公开 config 键值、secretKeys、credentialRef。机密值只存 Windows 凭据管理器，禁止写入 settings 或日志；高级配置默认机密，已知公开字段可以公开。
- OpenDAL 来源白名单仅限上述已编译服务；模板提供 GitHub 兼容、WebDAV 兼容与上述 OpenDAL 对象存储，高级配置可选择已编译 scheme 并填写键值。新 OpenDAL github 默认分支，旧任意分支来源继续可用。
- OpenDAL 测试检查读写列举删除能力，在唯一临时目录/对象写入、读回比较、列举、删除并确认清理；清理失败或能力不足不准启用。测试不能初始化或覆盖用户 library/catalog。配置修改使此前测试结果失效。凭据保存失败不可先启用源。
- 将 cloud.rs 中适用 WebDAV 协议编排泛化供 OpenDAL 复用，避免复制整个协议。GitHub 必须保留批量提交优化。远端 library/catalog/archives 格式不变；不要求重传或重建已有库。
- 所有远端路径必须受来源 root 限定，拒绝绝对路径、父路径、反斜杠穿越。删除目录要递归处理对象存储并限于目标前缀。元数据最后发布；失败不得删除之前已存在的快照。使用有界重试，401/403 不重试。
- meaningful tests: v2→v3 保真、密钥不入设置、能力/白名单拒绝、模拟或 memory backend 上传下载列举删除/临时清理、同步编排回归。不要访问真实用户云库或用对话历史 token。
- UI 遵循现有 Vue 主题变量、下拉控件、中文提示与图标 tooltip；模板和高级字段有明确标签与错误状态。
- 统一源版本 1.1.0 与 lockfiles；README 说明真实支持列表、兼容后端、OAuth 排除、高级配置、安全凭据与限制。
- 验证 cargo test --workspace；cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml；npm test、npm run typecheck、npm run build。

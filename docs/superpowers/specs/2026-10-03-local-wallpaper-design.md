# 本机自定义壁纸设计

## 目标与范围

用户可让自选图片铺满 Chronicle 的窗口内容区，并调节主要面板的透明度和背景磨砂度。壁纸只属于本机，不上传到云端，也不因下载云端应用设置而改变。现有强调色与日间、夜间、跟随系统模式继续独立工作。以 `docs/previews/custom-background-preview.png` 为视觉方向；它只是效果稿，不是待复制的产品代码。

本次不增加在线图库、轮播、按存档更换背景或跨设备图片同步。桌面 Windows 是完整支持目标；浏览器开发预览无法选择持久的本机壁纸时须明确提示，不伪装成已保存。

## 交互

- 软件设置中的外观区域先选背景类型：“主题纯色”或“自定义图片”；再选现有六种强调色和显示模式。选图片时不改变强调色。
- 图片模式提供本机图片选择、面板透明度和磨砂度控制。透明度定义为**面板透出壁纸的程度**：0% 不透出，45% 为允许的最大透出；默认 28%。磨砂模糊范围 0–24 px，默认 12 px。滑块带数值和键盘操作。
- 调整时即时预览窗口及设置内的小预览。只有点击既有“保存设置”才持久化；关闭、按 Esc 或点遮罩时，沿用未保存确认，放弃后恢复已保存的外观。
- 切回主题纯色仅停用壁纸，不删除所选图片；再切到图片可复用。提供明确的“移除图片”，保存后才删除本地副本。没有有效图片时不能保存启用的图片模式，并在控件附近显示原因。
- 背景铺在主界面标题栏、侧栏、存档列表和详情面板的底层。标题栏保持接近预览图的实色层；主要面板使用主题感知的半透明色和磨砂。输入框、内容卡片、弹窗和菜单维持更实的底色，避免繁忙图片压低可读性。主题纯色模式的现有外观不变。

## 数据与实现边界

- 图片及壁纸偏好保存在 Tauri 的本机应用数据目录，独立于资料库 `config/settings.json`。云端上传的 `app-settings.json` 不包含图片、路径、透明度或磨砂度；云端下载与资料库迁移不覆盖本机壁纸。
- 只接受静态 PNG、JPEG、WebP，按内容验证格式并限制文件大小为 15 MiB。选择时先验证并生成临时预览；保存时复制到本机应用数据目录，以临时文件加原子替换提交。应用启动读取本机副本，不依赖用户原始路径，因此原文件移动后仍可显示。
- 前端只拿经过验证的图像数据用于显示，不开放对用户主目录的宽泛 WebView 文件访问。图片或本机偏好损坏、缺失时回退主题纯色、保留其他设置并提示原因。
- 壁纸保存与现有设置保存在两个存储位置；任一保存失败时设置窗不关闭，显示已完成和待重试部分，不能提示全部成功。关闭确认比较两份草稿。系统明暗变化仍更新半透明面板的主题色。

## 验收

- 选择图片、调节两项滑块可即时预览；取消后恢复；保存并重启后保持。关闭图片模式后无壁纸，但重新启用可复用已选图。
- 重新选择图片、移除图片、原始文件被移动、本机副本损坏或偏好 JSON 损坏都有可理解的结果；无效格式及超过大小限制不会被保存。
- 云端应用设置上传不含壁纸数据；下载另一设备设置不覆盖本机壁纸。切换六种强调色及三种显示模式均不丢壁纸。
- 深浅主题、任意允许透明度和最小窗口尺寸下，文字、焦点、输入控件与弹窗保持可读；主题纯色模式与当前界面一致。运行相关前端、Rust 测试及 Windows 桌面检查。

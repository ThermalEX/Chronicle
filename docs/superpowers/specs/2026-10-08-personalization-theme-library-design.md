# 个性化、主题库与多图壁纸设计

日期：2026-10-08

状态：聊天交互方案已确认；本文待用户审阅，尚未进入产品代码实施。

## 1. 目标与范围

让用户在「纯色配色」和「定制主题」之间明确选择，并管理多个有名称、可编辑和切换的本机主题。主题包含配色、明暗模式、应用图标、壁纸列表、透明度、磨砂和五种事件音效，可导入、导出为同名 ZIP。

背景图片支持手动选择、定时随机和启动随机；切换用淡入淡出。设置预览必须作用于真实软件界面，而不是仅展示原图片。完成后用牧濑红莉栖主题重拍 README 的主工作区、云端设置、资料库管理和深色模式截图。

仅修改当前目录，保留既有未提交工作。外观资源和主题库仅供本机使用，不进入云端同步，不改变设备身份、资料库、备份和删除同步协议。本次不指定新版本，不创建或替换 Release。此前 v1.3.5 已在 GitHub 标为 Beta，v1.3.4 恢复为 Latest。

## 2. 已确认的交互

### 2.1 设置导航与主题类型

- 新增「个性化 / Personalization」标签；主题、配色、明暗模式、背景、图标和音效全部移入该标签，继续按卡片分组。
- 「软件」保留语言、启动、关闭和通知行为；设备、备份、回收站、热键、关于等现有标签不改职责。
- 个性化顶部使用二选一的主题类型：`纯色配色 / Solid colors`、`定制主题 / Custom themes`。
- 纯色模式显示预设配色、自定义强调色和明暗模式，不显示主题列表或主题资源编辑器。定制模式显示主题列表和选中主题的编辑器，不同时显示纯色模式的选择区；主题本身仍可编辑强调色。
- 两种模式分别保留选择，切换不会删除主题或图片。纯色模式不应用主题包的壁纸、图标和音效；使用纯色背景、默认图标和无主题音效。此处是为保证二选一语义明确的设计细化，并非清除资源。
- 明暗模式在当前模式的编辑区内显示，避免出现两个同时生效的控件。

### 2.2 主题列表与编辑

- 展示名称、缩略图和选中状态；提供新增、导入、重命名、切换及导出入口，不加入主题商店、在线下载或主题同步。
- 新增主题由当前定制主题复制为草稿；没有当前主题时从默认配色创建空主题。名称去除首尾空白，须为 1–64 个 Unicode 字符。
- 切换列表项先更新预览；各主题的未保存编辑保留在本次设置草稿中，不因切换列表而丢失。
- 用户可编辑名称、配色、明暗模式、图标、壁纸列表、背景效果和音效。主题可以没有壁纸或自定义图标，缺省时使用纯色背景或默认图标。
- 不增加独立保存按钮。新增、导入、改名、切换、修改图片和音效均计入未保存更改，统一由设置底部「保存设置」提交。
- 关闭、取消或按 Esc 时沿用现有保存／不保存／继续编辑对话框。放弃时恢复已保存外观和轮播状态，不留下已注册的新主题。

### 2.3 背景图片列表

- 图片区域显示缩略图列表，点击一张即可选中并预览；显示当前选中标记和图片名称。
- 没有图片时显示虚线添加区域，可点击打开多选图片窗口，或从资源管理器拖入图片。
- 有图片时保留一个同样的虚线添加格，用于继续添加；移除原来的「选择图片」和「移除图片」按钮。
- 每张图片右上角有删除图标，只从当前主题草稿移除该项，不删除原始文件。图标具备中英文名称、键盘操作和可见焦点。
- 删除选中项时选中剩余列表中的相邻项；删除最后一张后显示空列表并回退为当前主题纯色背景。
- 重复拖入相同文件不重复添加，显示提示。多文件中无效的文件逐项说明，其他有效图片仍可添加。
- 「预览软件界面」按钮在列表下方居中；预览沿用实际工作区与返回入口，不使用图片缩略图代替软件效果。
- 透明度与磨砂控件保留，以真实软件界面为预览目标。

### 2.4 图片切换方式

提供三种互斥方式：

1. `不自动切换 / Keep selected image`：固定选中图片，仍允许手动切换。
2. `定时随机 / Random at intervals`：用户输入间隔，可选择秒或分钟；内部保存为秒，默认 60 秒，接受 1–86400 秒的整数。无效值阻止保存，不悄悄修改输入。
3. `启动随机 / Random on startup`：每次完整启动程序时随机选择一次，运行中固定。打开设置、保存、从托盘恢复窗口或切换明暗模式不重新触发启动随机。

补充行为：

- 多张图片时随机选择排除当前项；只有一张时保持固定，不启动无意义的定时器。
- 运行时随机结果不不断写入设置，也不将随机轮播本身视为用户未保存更改；用户手动点击的选择才进入草稿。
- 打开设置时暂停已保存外观的自动轮播，使用独立草稿预览；返回工作区后恢复保存状态。定时随机的草稿可在实际软件预览中验证，退出预览即停。
- 切换前先加载目标图；加载成功才用两层图片交叉淡入淡出，保留旧图直至过渡结束，避免闪白和黑场。
- 默认过渡 0.7 秒；快速连续手动选择只保留最新请求，不让旧加载结果覆盖新选择。
- 尊重减少动态效果设置，关闭渐变但仍可切换图片。
- 主题、模式或间隔变化，退出预览、组件卸载时释放定时器和待加载请求。后台恢复不补播累积的切换。
- 某张图损坏或丢失时保留可读图片，给出诊断；全部不可读时退回主题纯色，不删除列表或猜测新路径。

## 3. ZIP 主题与声音包

### 3.1 主题文件格式

新主题采用 `formatVersion: 2`，根目录含 `theme.json` 和资源子目录。配置使用已有驼峰命名习惯，记录：

- `name`：主题显示名称。
- `colorTheme`、`customAccent`、`colorMode`：复用现有配色类型。
- `transparency`、`blurPx`：沿用当前有效范围 0–45、0–24。
- `icon`：可选的相对路径。
- `wallpapers`：按顺序保存图片相对路径数组；`selectedWallpaperIndex` 为固定选择。
- `wallpaperPlayback`：`fixed`、`intervalRandom`、`startupRandom`；`intervalSeconds` 保存自定义间隔。
- `sounds`：复用 `enabled`、`volume` 与五种事件对应的 `files` 相对路径。

示例文件布局：

```text
牧濑红莉栖.zip
├── theme.json
├── icon.png
├── wallpapers/
│   ├── 001.jpg
│   └── 002.png
└── sounds/
    ├── connected.wav
    └── notification.wav
```

名称不作为本机存储目录或身份。每个本机主题拥有独立 UUID，防止同名导入覆盖已有主题。JSON 有名称时优先使用；旧格式缺少名称时回退到 ZIP 文件名或配置所在文件夹名。同名导入生成可区分的名称后缀，不覆盖旧主题。

### 3.2 导入与导出

- 导入接受新 ZIP 和已有 `formatVersion: 1` 的 `theme.json` 文件夹形式；旧单张 `wallpaper` 转为一个图片列表，默认不自动切换。
- 导入先校验配置和全部引用资源，再加入设置草稿；坏包不覆盖已有主题或当前已保存设置。
- 导出时明确选择要导出的主题。若该主题在本次设置中已编辑，导出草稿；其他主题导出其当前保存内容。
- 文件名称默认是 `主题名称.zip`。Windows 不合法文件名字符只在输出文件名中替换，JSON 内保留原主题名称。存在同名输出时提示另选名称或确认覆盖，不自动覆盖。
- 导出把所有列表图片、图标、声音、选择和轮播配置放进包中，不含本机绝对路径、设备信息、云端配置或其他主题。
- 导出不保存设置；随后放弃设置不会删除用户明确导出的 ZIP。
- ZIP 先写临时文件，完成后再发布；失败不留下看似有效的半包。
- 牧濑红莉栖和粉蓝插画都生成独立的有名称 ZIP，本机使用，不默认附带到软件安装包。

### 3.3 声音包

- 音效卡片增加「导入声音包」，用于将一组音效加入当前主题草稿；原有单事件选择、移除、试听、总开关和音量仍保留。
- 声音包是 ZIP，根目录包含 `sounds.json`，结构为 `formatVersion: 1`、可选 `name` 和复用的 `sounds` 配置。也接受主题 ZIP 内的音效部分，仅更新音效，不覆盖主题配色、名称、图标和壁纸。
- 根据清单中的五个事件键映射，不根据任意文件名猜测事件；声音包未提供的事件保留当前草稿的音效，提供的事件替换对应项。
- 全部音效验证完成后才更新草稿；失败不部分替换。继续使用现有 PCM WAV 限制，每文件不超过 5 MiB、30 秒。
- 不修改 Windows 系统音效；草稿不会自动播放，仅明确试听才播放。保存后沿用现有事件播放与防叠加机制。
- 将用户提供的 Rayburst 五个 WAV 整理为可导入声音包，并纳入本机牧濑红莉栖主题；不默认启用所有用户的音效。

### 3.4 ZIP 与资源安全

- 只支持普通 ZIP 文件，不执行脚本、安装字体或访问配置中的网络地址。
- 拒绝绝对路径、父级路径、Windows 盘符、符号链接、加密项、大小写冲突与重复文件项；所有引用必须位于包内。
- 配置文件不超过 64 KiB，单张图片沿用 15 MiB 限制，最多 32 张；整个 ZIP 及实际解压资源总量不超过 256 MiB。
- 逐流计数实际解压字节，不仅信任 ZIP 目录中声明的大小；只使用验证过的相对路径。
- 解压到本机应用资产区的独立临时目录，取消或失败只清理由本次导入创建的文件。损坏／超限包不能改变已保存主题。

## 4. 实现边界与持久化

采用在现有外观功能上扩展本机主题库的方案，不建立第二套配色或音效渲染器。比仅用文件夹快捷方式多出本机持久化，但能支持编辑后打包、统一保存和移走原 ZIP 后继续使用。

- Rust 负责读取、验证、暂存、保存和打包资源；沿用 `wallpaper.rs` 图片验证、`local_sound.rs` 音效验证、`local_icon.rs` 原生窗口／托盘图标应用。
- 将主题包和主题库职责放入专用模块，避免继续把 ZIP、列表持久化都堆入 `local_icon.rs`。只移动与本次任务相关的代码，不顺带重构云端或备份。
- 新本机个性化入口负责主题模式、纯色设置、主题目录引用和选中主题。该配置不加入共享资料库／云端设置，也不下载远端外观资源。
- 沿用已修复的 `storage_root::local_assets_root`：安装版使用原应用资产位置，便携版使用自身 `Chronicle-data`，不跨实例读取安装版测试图片。
- 每次保存先验证全部个性化草稿，写入独立的新资源版本目录；最后原子替换本机个性化配置，统一引用完整的新版本。失败保留旧配置和资源，不发布半个主题。
- 主题目录不是依赖原 ZIP 的外部链接，保存时复制所需资源；之后移动原始图片或 ZIP 不影响已保存主题。
- 旧外观文件首次加载时转换为「当前主题」草稿，保留旧文件；首次成功保存新个性化数据后使用新入口。旧设置有图片壁纸、自定义图标或自定义音效资源时迁移为定制主题；仅有预设／自定义强调色和明暗设置时迁移为纯色模式，不误开主题库。
- 缺少新配置时使用旧读取逻辑；损坏时报告警告并使用可恢复的配置备份或默认纯色，不能误显示为成功迁移。
- Vue 服务管理已保存状态与设置草稿；壁纸运行器独立负责预加载、随机选择和定时器，组件负责两图层渐变和列表交互。
- 设置保存成功后同步应用配色、壁纸、音效与原生图标。预览使用真实软件的配色、壁纸和关于页图标；原生任务栏／托盘图标仅在保存后更新。
- 个性化事务与其他软件设置使用现有部分成功诊断，不扩展成资料库级事务。任一部分失败不声称全部保存，保留未提交草稿供重试。

## 5. 拖入路径路由与界面一致性

- 复用 Tauri 的窗口拖放事件，设置打开且位于个性化图片区域时，将图片交给该区域；禁止再触发「创建存档」。
- 仅当鼠标落在可见添加区域／图片列表内才接收壁纸，不将拖入设置任意位置理解为添加图片。
- 设置关闭时继续保持既有文件／文件夹拖入创建存档行为；其他弹窗和标签不消费壁纸拖放。
- 同时保留可点击的文件选择入口和键盘操作，不要求用户必须拖放。
- 复用现有主题颜色、卡片、按钮、对话框和诊断样式，不增加独立视觉体系。
- 新导航、主题名称校验、切换方式、间隔单位、空状态、删除辅助标签、ZIP／声音包错误和保存确认均补齐中英文。外部主题的自定义名称原样显示，不作为翻译键。
- 最小窗口 1024×720 下列表换行，卡片不溢出；主题预览和关闭操作不阻塞。

## 6. 验收与交付

按测试驱动实施，先写失败测试，再完成对应功能：

1. 模式互斥：纯色不显示主题库，切到主题时恢复原选择；放弃不留下新主题，纯色配置不被主题编辑覆盖。
2. 主题列表：新增、改名、编辑多个主题、切换和重启保持；同名导入不覆盖；损坏导入不改变保存状态。
3. ZIP 回环：选定主题草稿导出为同名 ZIP，导入后名称、全部图片、选择、播放方式、配色、图标和声音一致；导出不保存设置。
4. 图片列表：空态点击／多选／拖入有效，单项删除不删除源文件；重复和无效文件有提示；拖放不创建存档。
5. 随机与过渡：自定义间隔、固定、启动随机分别验证；启动随机只触发一次，单图无定时器，多图不连续重复当前项；加载失败不黑场，连续点击不被旧请求覆盖；减少动态效果有效。
6. 保存保护：预览、关闭不保存、恢复默认、保存后重开均一致；主题事务中断或资源写入失败可安全重试。
7. 声音包：导入只更改对应事件，试听不保存，保存后事件播放正确，缺损／过长 WAV 拒绝；完整主题包缺省音效不继承另一个主题。
8. 安全：ZIP 路径穿越、链接、重名、超限、压缩炸弹、非法名称、缺失文件测试通过。
9. 隔离：便携版不加载安装版外观，不改用户真实资料库、旧快照、设备 UUID 和云端配置。
10. 运行完整前端测试、类型检查、构建，相关 Rust 测试与检查、工作区测试和检查；不意外升级 Tauri 或锁文件中的无关依赖。
11. Windows 桌面验证中英文、深浅色、最小窗口、点击／拖入、托盘恢复和关闭重开。既有运行进程占用构建文件时使用隔离构建产物，不擅自结束用户进程。
12. 使用独立演示资料库，在牧濑红莉栖主题下重拍 README 四张真实软件截图；隐藏个人路径和真实云端凭据。截图公开前检查文字清晰、图标一致、布局无溢出。

产品实现、主题 ZIP／声音包和 README 新截图属于后续实施交付。本文不是已完成功能清单，当前不宣称这些功能已运行或已发布。

# Chronicle

Chronicle 是一个面向任意文件和文件夹的本地优先存档管理器。用户可以创建多个时间节点的不可变快照，将存档保存在本地或 WebDAV，并按分类查询、恢复和同步。

## 设计目标

- 管理游戏存档、软件配置、创作工程及普通文件目录。
- 支持手动备份、计划备份、文件变化触发和退出应用时备份。
- 本地数据始终可独立使用，WebDAV 作为可选副本。
- 快照只追加不覆盖；恢复、删除和同步均可审计。
- 核心逻辑与桌面界面、数据库、压缩格式和远程协议解耦。

## 技术栈

- Rust：领域模型、快照、校验、同步和平台能力。
- Tauri 2：桌面应用外壳和系统集成。
- Vue 3、TypeScript、Vite：用户界面。
- SQLite：分类、条目、快照索引、任务和同步状态。
- 本地文件系统与 WebDAV：可插拔存储后端。

完整方案见 [架构设计](docs/architecture.md)。
